## Overview

Boot is a personal collection of **distilled bootstrap notes** for
spinning up a dev environment fast and turning ideas into shipped work
with as little friction as possible.

The folder is intentionally small and grabbable. Notes go in
[`./note`](./note). Scripts go in [`./task`](./task). Everything is
short, scannable, and meant to be skimmed in seconds, not studied.
